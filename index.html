Core Capabilities

🔍

Deep Inspection

Extract detailed model info, generate ASCII or Graphviz visualizations, and analyze node-level statistics and shapes.

✂️

Pruning & Stripping

Remove unused nodes, disconnected inputs/outputs, dead branches, and strip training metadata or docstrings.

⚡

Quantization

Convert models to FP16 half-precision or INT8 (dynamic/static) for massive speedups and 75% size reduction.

📊

Diff & Reporting

Compare two model versions structurally. Generate comprehensive interactive HTML analysis reports.

🔧

Graph Simplification

Automatically fold constants, fuse BatchNormalization into Convolutions, and remove Identity no-ops.

🧮

FLOP & Param Counting

Accurately estimate FLOPs, MACs, and total parameter counts per operator and for the whole model.

git clone https://github.com/Luv-Goel/onnx-model-surgery.git
cd onnx-model-surgery
pip install -e ".[dev,viz,quant]"

Usage Guide

The toolkit provides the oms CLI command. Here are the most common operations:

1. Analyze FLOPs & Parameters

oms flops model.onnx

2. Compare Models (Diff)

oms diff model_v1.onnx model_v2.onnx
# Or generate an interactive HTML report
oms diff-report model_v1.onnx model_v2.onnx -o diff.html

3. Strip Metadata & Optimize

oms strip model.onnx --strip-docs --optimize extended -o clean.onnx

4. Quantize to FP16

oms quantize model.onnx --mode fp16 -o model_fp16.onnx
