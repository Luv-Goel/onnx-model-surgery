ONNX Model Surgery 🔪

Visual ONNX model inspection, pruning, patching, quantization, and optimization toolkit.

Features

🔍 Inspect

Detailed model info, graph visualization, node-level statistics.

✂️ Prune & Strip

Remove unused nodes, inputs, outputs, branches, and metadata.

⚡ Quantize

FP16 half-precision and INT8 dynamic/static quantization.

📊 Diff & Report

Generate comprehensive HTML analysis and diff reports.

Quick Start

pip install onnx-model-surgery

# Display model metadata
oms info model.onnx

# Prune unused nodes
oms prune model.onnx --output pruned.onnx

# Count FLOPs
oms flops model.onnx
